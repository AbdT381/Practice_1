 Shell Emulator (Вариант №1)

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой (VFS) в памяти.

 Общее описание

Приложение реализовано в виде консольного интерфейса (CLI). Поддерживает:
- REPL с приглашением, содержащим имя VFS;
- раскрытие переменных окружения реальной ОС (`$HOME`, `$USER` и т.д.);
- команды: `ls`, `cd` (заглушки на этапе 1, полноценные на этапе 4 — здесь реализованы базово для этапа 3), `exit`, `conf-dump`;
- загрузку VFS из CSV-файла (в памяти, без модификации исходного файла);
- стартовый скрипт, выполняемый при запуске (останавливается на первой ошибке);
- отладочный вывод параметров при запуске.

 Описание функций и настроек

 Параметры командной строки
| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | Путь к CSV-файлу VFS. Если не указан — создаётся VFS по умолчанию в памяти. |
| `--script PATH` | Путь к стартовому скрипту. Если не указан — интерактивный режим. |

 Команды эмулятора
| Команда | Описание |
|---------|----------|
| `ls [PATH]` | Вывод содержимого каталога. |
| `cd PATH` | Смена текущего каталога. |
| `exit` | Выход из эмулятора. |
| `conf-dump` | Вывод текущих параметров эмулятора в формате ключ-значение. |
| `echo ARGS...` | Вывод аргументов (реализовано для этапа 3 как вспомогательное). |

 Переменные окружения
Поддерживается раскрытие `$VAR` и `${VAR}` из окружения реальной ОС.

 Сборка и запуск

```bash
 Запуск в интерактивном режиме с VFS по умолчанию
python src/emulator.py

''' Запуск с указанной VFS '''
python src/emulator.py --vfs vfs/files.csv

''' Запуск со стартовым скриптом '''
python src/emulator.py --vfs vfs/deep.csv --script start_scripts/start_stage3.txt
